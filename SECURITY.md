# Security

Report vulnerabilities responsibly.

- **Preferred:** open a private report via GitHub Security Advisories on this repository, or file a minimal public issue without exploit details if advisories are unavailable.
- **Contact / policy pointer:** production hosts should serve [RFC 9116 `security.txt`](https://alagoas.precospublicos.ia.br/.well-known/security.txt) (see `deploy/well-known/security.txt` in-tree, issue #171).
- **Languages:** Portuguese or English.

Please include affected host/component (app, API, admin, docs), impact, and reproduction steps. Do not include real device tokens, admin bearers, or personal data in reports.
