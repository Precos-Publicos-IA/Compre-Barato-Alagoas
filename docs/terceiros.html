Terceiros & atribuições

O código deste repositório é MIT (Preços Públicos IA). O produto depende de fontes de dados, bibliotecas e ativos de terceiros com licenças e termos próprios. Esta página resume o essencial para usuários, operadores e listagens em lojas; detalhes técnicos em THIRD_PARTY.md na raiz do repositório.

Escopo

Não substitui o arquivo LICENSE de cada dependência. Em revisões formais, gere a árvore atual com flutter pub deps e o manifesto Python do backend.

Fontes de dados

FontePapelObservação
SEFAZ-AL — Economiza Alagoas Preços/ofertas em produção (USE_MOCK_SEFAZ=false) API pública governamental; token só no servidor. Termos de uso e emissão do token são da SEFAZ-AL / Estado de Alagoas. Este app é intermediário — não é dono dos dados fiscais.
Catálogo mock (mock_sefaz.json) Desenvolvimento e testes Dados sintéticos do projeto; não são NFC-e reais.

Mapas & localização

  • OpenStreetMap — tiles via flutter_map. © colaboradores do OpenStreetMap; licença de dados ODbL. A interface deve exibir atribuição OSM (issue #164).
  • Localização do dispositivo — opcional (fallback Maceió); políticas de permissão do SO/navegador se aplicam.

Runtime & bibliotecas (visão geral)

  • Flutter / Dart — motor e framework (licenças BSD-style do projeto Flutter).
  • Plugins Flutter — ex.: http, armazenamento seguro, geolocator, speech_to_text, share_plus, url_launcher, app_links, flutter_map, riverpod — ver cada pacote em pub.dev.
  • Backend — FastAPI, Redis client, httpx, cryptography (Fernet), gunicorn/uvicorn, clientes SEFAZ/LLM, Sentry opcional — ver dependências Python do diretório backend/.
  • Painel admin — HTML/JS/CSS próprios; Chart.js vendido em admin-frontend/vendor/ (MIT típico; confirmar comentário do arquivo; issue #193 sobre source map ausente).
  • E2E — Puppeteer/Chromium em e2e/.

Manutenção

Atualize esta página e THIRD_PARTY.md ao adicionar código vendido, mudar provedor de mapas ou integrar SDKs de loja/push/anúncios. Questionários de privacidade (Play / App Store — issues #262, #270) devem apontar para aqui e para as páginas de LGPD, evitando divergência entre “o app declara” e “o código faz”.

Não incluídos por padrão no código atual: FCM/Web-Push, SDKs de anúncio ou analytics de terceiros; medição de uso é agregada no próprio backend (ver LGPD · medição de uso).
